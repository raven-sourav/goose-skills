# Meta Ad Library Scraper — Internal Brief

**Prepared for:** Meta/Ads team review
**Date:** 2026-03-10
**Status:** Ready for testing
**Risk level:** Low (official API, no scraping)

---

## 1. What Is This?

A Python script that queries **Meta's official Ad Library API** (Graph API) to pull competitor ad data. This is the same public API that tools like Semrush, SpyFu, and Pathmatics use under the hood.

**This is NOT scraping.** We're making authenticated API calls to an endpoint Meta built and maintains for public ad transparency (mandated by EU Digital Services Act).

---

## 2. What We're Pulling (Data Model)

### Per Ad — Creative & Copy

| Field | Description | Use Case |
|-------|-------------|----------|
| `ad_text` | Primary ad body copy | Messaging analysis, tone comparison |
| `link_title` | Headline shown in ad CTA | Hook/headline pattern analysis |
| `link_description` | Description below the headline | Value prop extraction |
| `link_caption` | Display URL shown in ad | Landing page tracking |
| `ad_snapshot_url` | Meta-hosted screenshot of the ad | Visual creative review |

### Per Ad — Performance Signals

| Field | Description | Use Case |
|-------|-------------|----------|
| `spend_lower` / `spend_upper` | Spend range (e.g., $100-$499) | Budget benchmarking |
| `impressions_lower` / `impressions_upper` | Impression range (e.g., 1K-5K) | Reach estimation |
| `estimated_audience_size` | Target audience size estimate | Targeting strategy analysis |
| `currency` | Spend currency | Normalization for multi-market |

### Per Ad — Distribution

| Field | Description | Use Case |
|-------|-------------|----------|
| `platforms` | facebook, instagram, messenger, threads, whatsapp | Platform mix strategy |
| `demographic_distribution` | Age/gender breakdown of audience reached | Audience targeting review |
| `delivery_by_region` | Geographic distribution of impressions | Geo-targeting analysis |
| `languages` | Ad languages | Market/locale identification |

### Per Ad — Timing

| Field | Description | Use Case |
|-------|-------------|----------|
| `start_date` | When the ad started running | Campaign launch tracking |
| `stop_date` | When it stopped (null if still active) | Campaign duration analysis |

### Per Ad — Advertiser

| Field | Description | Use Case |
|-------|-------------|----------|
| `page_name` | Advertiser's Facebook Page name | Competitor identification |
| `page_id` | Facebook Page ID | Cross-reference campaigns |
| `bylines` | "Paid for by" disclosure | Identify agency vs. in-house |

---

## 3. What We CAN'T See

The API does NOT expose:
- Click-through rates (CTR)
- Conversion data
- Exact spend (only ranges)
- Exact impressions (only ranges)
- Targeting criteria (interests, lookalikes, custom audiences)
- A/B test variants (each version appears as a separate ad)
- Creative assets directly (images/videos require visiting the snapshot URL)

## 4. How It Works (Technical Flow)

```
┌─────────────────┐
│ Our Script      │
│ (Python)        │
└────────┬────────┘
         │  HTTPS GET /ads_archive
         │  + App Token (not personal token)
         │  + search_terms, country, fields
         ▼
┌─────────────────┐
│ Meta Graph API  │
│ v21.0           │
│ /ads_archive    │
└────────┬────────┘
         │  JSON response
         │  Paginated (25 per page, cursor-based)
         ▼
┌─────────────────┐
│ Normalized      │
│ Ad Data (JSON)  │
└─────────────────┘
```

### Authentication

Two options (we recommend Option A):

**Option A: App Token (recommended — safest)**
- Generated from `META_APP_ID` + `META_APP_SECRET`
- NOT tied to any personal Facebook account
- If revoked, only the app is affected — no personal account risk
- Automatically generated by the script

**Option B: User Access Token**
- Generated from Graph API Explorer
- Tied to a personal Facebook account
- Expires every ~60 days
- Only use if App Token doesn't work for your use case

### Rate Limits & Safety

| Safeguard | Implementation |
|-----------|---------------|
| Rate limiting | 2-second delay between page fetches (well within 200 calls/hour) |
| Backoff on 429 | Reads `Retry-After` header and waits automatically |
| Max results cap | `--max-ads` flag prevents runaway queries |
| No browser automation | Pure HTTPS API calls — no Puppeteer, Selenium, or headless browsers |
| No cookie/session hijacking | Uses official OAuth tokens only |

## 5. Setup Guide

### One-time setup (~5 minutes)

1. Go to https://developers.facebook.com/apps/
2. Click **Create App**
3. Select **Other** → **Business**
4. Name it (e.g., "Ad Research Tool") → Create
5. Go to **App Settings** → **Basic**
6. Copy **App ID** and **App Secret**
7. Set environment variables:

```bash
export META_APP_ID="your_app_id_here"
export META_APP_SECRET="your_app_secret_here"
```

No app review or special permissions needed for Ad Library API access.

```bash
python3 search_meta_ads_direct.py --search "HubSpot" --country US --output summary
```

```bash
python3 search_meta_ads_direct.py --search "Salesforce" --country US --output detailed
```

```bash
python3 search_meta_ads_direct.py --search "CRM software" --max-ads 50 --output json
```


```bash
python3 search_meta_ads_direct.py --search "Nike" --output json > nike_ads.json
```

## 7. Creative Download & Image Analysis

### Download creatives with structured taxonomy

```bash
# Search + download in one step
python3 download_ad_creatives.py --search "HubSpot" --country US --max-ads 20

# From previously saved JSON
python3 download_ad_creatives.py --from-json hubspot_ads.json

# Metadata only (no image download)
python3 download_ad_creatives.py --search "Shopify" --metadata-only
```

### Folder taxonomy

```
ad_creatives/
├── manifest.json                              ← master index of all ads
├── analysis_brief.md                          ← analysis prompt + ad index table
├── raw_api_response.json                      ← raw API data for reuse
├── hubspot/
│   ├── 2026-02-15_facebook_instagram_hubspot_83721/
│   │   ├── creative_1.jpg                     ← primary ad image
│   │   ├── creative_2.jpg                     ← carousel slide / variant
│   │   └── metadata.json                      ← copy, spend, impressions, etc.
│   ├── 2026-01-20_facebook_hubspot_44102/
│   │   ├── creative_1.png
│   │   └── metadata.json
├── salesforce/
│   └── ...
```

**Naming convention:** `{start_date}_{platforms}_{company}_{hash}/`
- Sorted chronologically by default
- Grouped by advertiser
- Each ad folder is self-contained (creative + metadata)

### What gets auto-generated

1. **manifest.json** — master index with all ads, folder paths, spend ranges, creative counts
2. **analysis_brief.md** — structured analysis prompt covering visual patterns, messaging, format strategy, performance signals, and competitive gaps
3. **metadata.json** (per ad) — full ad copy, link titles, spend, impressions, demographics, regions

### Image analysis dimensions (in analysis_brief.md)

| Dimension | What to look for |
|-----------|-----------------|
| Visual patterns | Color palette, composition, text overlay, faces vs. product |
| Messaging | Hook type, value prop framing, CTA language, emotional tone |
| Format strategy | Static vs. carousel vs. video, platform adaptations |
| Performance signals | Long-running ads = winners, high spend = confidence |
| Competitive gaps | Missing visual styles, underserved platforms, creative fatigue |

## 8. Competitive Analysis Playbook

### What to analyze from the data

**1. Messaging Patterns**
- What hooks are competitors using? (questions, stats, pain points, social proof)
- How do they describe their product in 1-2 lines?
- What CTAs are they testing? (Learn More, Sign Up, Get Started, Shop Now)

**2. Creative Strategy**
- Platform mix: are they heavy on Instagram vs. Facebook?
- Are they running video or static? (check snapshot URLs)
- How many ad variants are they running simultaneously?

**3. Budget & Scale Signals**
- Spend ranges reveal relative investment levels
- Impression ranges show reach strategy
- Long-running ads (weeks/months active) = likely high performers
- Recently launched ads = new campaigns or tests

**4. Timing & Cadence**
- How frequently do they launch new ads?
- Do they have seasonal patterns?
- How long do their campaigns run before refreshing?

**5. Audience Signals**
- Demographic distribution reveals target personas
- Regional delivery shows geographic priorities
- Language targeting shows market expansion strategy

### Recommended workflow

```
Weekly:
  1. Pull active ads for top 3-5 competitors
  2. Compare messaging themes vs. previous week
  3. Flag new campaigns (ads with recent start dates)
  4. Note ads running 30+ days (likely winners worth studying)

Monthly:
  1. Pull all ads (active + inactive) for broader trend analysis
  2. Map messaging evolution over time
  3. Identify which ad types/platforms competitors are investing in
  4. Feed insights into your own creative brief
```
